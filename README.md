# 秋の優光泉 味くらべフェア｜5つの味の飲みくらべBOX LP

断食道場shop（楽天）向け、個包装「ポケット優光泉」5つの味・6包の飲みくらべBOX（1,000円ポッキリ）の本番用ページです。

- `index.html` … 本番版（v2）
- `proposal-v1.html` … 社内提案用の初版（2味・ボトル想定）。参考として残しています

## BOX内容
ポケット優光泉 20ml × 6包
スタンダード2包、梅1包、ミカン（みかん味）1包、ザクロ（ザクローズ）1包、和漢（濃縮 和漢 発酵）1包

## 構成
1. FV：6包の個包装モチーフ＋「5つの味、どれが好き？」＋1,000円ポッキリ
2. はじめての方／いつもの方
3. BOXの中身
4. おすすめの飲む順番（スタンダードが2包入っている理由）
5. 推し味ノート（5段階で好き度をつけると推し味と商品リンクを表示）
6. 推し味が決まったら（各味の15包商品へのリンク）
7. 購入・商品概要
